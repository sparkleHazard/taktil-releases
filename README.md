# Taktil Releases

Public release feed for [Taktil](https://github.com/sparkleHazard/taktil) (private repo).

- `appcast.xml` — Sparkle update feed polled by installed apps
- `Taktil-<version>.zip` — notarized app archives referenced by the appcast

Published automatically by Taktil's release workflow on every `v*` tag.
Do not edit by hand — contents are overwritten by CI.
